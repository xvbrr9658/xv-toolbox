## 二、VPS 安装与部署方法 (极其简单)

因为你的酒馆是部署在自己的 VPS 上的，安装只需要将文件夹上传至标准插件目录即可：

### 目录结构要求
请确保在 VPS 上的酒馆路径下放置为如下目录：
```text
SillyTavern/
  └── public/
      └── scripts/
          └── extensions/
              └── third-party/
                  └── xv-toolbox/            <--- 插件文件夹
                      ├── manifest.json
                      ├── index.js
                      ├── templates.js
                      ├── style.css
                      └── README.md
```

### 部署步骤（任选其一）

#### 途径 A：宝塔面板 / 1Panel 上传
1. 登录你的 VPS 宝塔面板或 1Panel，进入文件管理。
2. 打开路径：`SillyTavern/public/scripts/extensions/third-party/`。
3. 把解压后的 `xv-toolbox` 整个文件夹直接上传进去（或者直接上传 `xv-toolbox.zip` 并在该目录下解压）。
4. 清理浏览器缓存或按 `Ctrl + F5` 刷新你的云酒馆网页，插件即刻自动加载！

#### 途径 B：SSH 终端命令行
如果你习惯用终端连接 VPS：
```bash
cd /path/to/SillyTavern/public/scripts/extensions/third-party/
# 将 xv-toolbox 文件夹放入此目录即可
ls -la xv-toolbox/
# 确认看到 manifest.json, index.js, style.css 等文件
```

## 三、常见疑问与共存说明

1. **会和“酒馆助手”或“柏宝箱”打架吗？**
   * **绝对不会**。本插件的所有 CSS 样式、变量、ID 全部采用 `xv-tb-*` 独立命名空间，逻辑完全封装在安全闭包内，绝不污染全局，与任何第三方美化或管理插件完美共存。
2. **更新酒馆会把这个插件冲掉吗？**
   * **绝对不会**。酒馆的 `third-party` 目录受官方 `.gitignore` 保护，任何 `git pull` 或自动更新都不会触碰你的第三方插件。
3. **支持手机端 / 平板操作吗？**
   * **完全支持**。悬浮球支持移动端手指触控拖拽，弹窗支持响应式自适应宽度，在手机浏览器里操作同样丝滑。
